# Bank Management System

A console-based Bank Management System developed using C++.

## About the Project

This project is a console-based banking system that allows users to
manage bank clients and perform basic banking transactions.

Client information is stored and managed using file handling.

## Features

### Client Management
- Add a new client
- Update client information
- Delete a client
- Find a client
- Display all clients

### Transactions
- Deposit money
- Withdraw money
- Show total balances

## Technologies Used

- C++
- File Handling (`fstream`)

## Project Purpose

This project was developed to practice C++ programming and file
handling by building a complete console-based Bank Management System.
